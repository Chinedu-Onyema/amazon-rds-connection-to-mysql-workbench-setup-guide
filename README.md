# Creating an Amazon RDS MySQL Instance and Connecting an On-Premise MySQL WorkBench Database

This repository contains step-by-step instructions for provisioning an Amazon Relational Database Service (RDS) MySQL instance, configuring its security and public access settings, and connecting to it externally using MySQL Workbench to execute SQL commands.

#### PDF GUIDE: [CREATE AN AMAZON RELATIONAL DATABASE SERVICE INSTANCE AND CONNECT AN ON-PREM MYSQL DATABASE.pdf](https://github.com/user-attachments/files/32696655/5.CREATE.AN.AMAZON.RELATIONAL.DATABASE.SERVICE.INSTANCE.AND.CONNECT.AN.ON-PREM.MYSQL.DATABASE.pdf)

## PREREQUISITES

- An active [AWS Account](https://aws.amazon.com/).
- [MySQL Workbench](https://www.mysql.com/products/workbench/) installed on your local computer.

---

## STEP-BY-STEP DEPLOYMENT GUIDE

### Step 1: Create a Security Group
1. Go to your AWS Management Console and search for **EC2**.
2. Navigate to **Security Groups** on the left-hand menu and click **Create security group**.
3. Configure the settings:
   - **Security group name:** `db_connect_example`
   - **Description:** Allow inbound traffic for database connection.
4. **Inbound Rules:**
   - **Type:** All Traffic
   - **Source:** Anywhere-IPv4 (`0.0.0.0/0`)
5. **Outbound Rules:** Leave at default.
6. Click **Create security group**.

---

### Step 2: Configure and Create the RDS MySQL Instance
1. Search for **RDS** or **Aurora** in the AWS Management Console search bar and navigate to the RDS service.
2. Click **Databases** on the left side of the console, then click **Full configuration**.
3. **Engine Options:** Select **MySQL** and match the version corresponding to your requirement (e.g., MySQL version `8.0.40`).
4. **Templates:** Select **Free Tier** (or your preferred tier).
5. **Settings:**
   - **DB instance identifier:** `tutorialdatabase-1`
   - **Master username:** `admin`
6. **Credential Management:** 
   - Select **Self manage**.
   - Check the **Autogenerate a password** box (or create your own). 
   - *Important:* Save this password in a secure place or separate sheet, as you will need it to connect.
7. **Storage:** Select **General Purpose SSD (gp3)** for lower RDS cost.
8. **Connectivity:**
   - **Compute resource:** Choose **Don't connect to an EC2 compute resource**.
   - **VPC:** Specify your desired VPC (or leave default).
   - **Public access:** Select **Yes** (required so that the RDS instance can connect from your local/on-premise machine).
   - **VPC security group (Firewall):** Select **Choose existing compute security group** and choose the `db_connect_example` security group you created in Step 1.
9. **Additional Configuration:**
   - Locate **Backup** and uncheck **Enable automated backups**, **Enable encryption**, and any other boxes that might incur unexpected costs.
10. Leave all other settings as default and click **Create database**.

---

### Step 3: Retrieve Connection Details
1. Once the database is created, click **View connection details** and copy the autogenerated master password, saving it securely.
2. Wait for the database instance **Status** to change from *Creating* to **Available**.
3. Click on your database name URL (`tutorialdatabase-1`), go to the **Connectivity & security** tab, and locate the **Endpoint** and **Port**. Copy the **Endpoint URL**.

---

### Step 4: Connect to RDS Using MySQL Workbench
1. Open **MySQL Workbench** on your computer and click the **`+`** button next to MySQL Connections to set up a new connection.
2. Fill out the connection parameters:
   - **Connection Name:** `myrdsconnection`
   - **Hostname:** Paste the Endpoint URL copied from your RDS instance.
   - **Username:** Change from `root` to `admin`.
   - **Password:** Click **Store in Vault** and paste the autogenerated password provided by AWS, then click **OK**.
3. Click **Test Connection**. If successful, a confirmation message will pop up. Click **OK**, then click **OK** again to save the connection.

---

### Step 5: Initialize Database and Tables
1. Click on your newly created connection (`myrdsconnection`) to open a new SQL query workspace tab.
2. Run the following SQL queries by highlighting the text and executing them:

- **Create a new database in the RDS instance:**
  ```sql
  CREATE DATABASE exampledb;
  ```

- **Use the newly created database:**
  ```sql
  USE exampledb;
  ```

- **Create an employee directory table:**
  ```sql
  CREATE TABLE employees_directory (
      emp_id INT,
      emp_name VARCHAR(255)
  );
  ```
